## Запуск пакета (практика, пункты 2–4)

Подготовлен самостоятельный сценарий мультиклассовой логистической регрессии.
Python 3.11–3.12, Poetry 2.2.1. Команды из корня репозитория:

```bash
poetry install --with dev
poetry run pre-commit install
poetry run pytest -q
poetry run cirrhosis-train --config configs/train.toml
poetry run cirrhosis-predict --input data/raw_data.csv
```

Модель, актуальные метрики и предсказания записываются в `artifacts/`.
Пример предсказания на raw_data.csv проверяет интерфейс, а не качество на новых данных.
Подробная инструкция для Windows и соответствие заданию: [PRACTICE_2_3_4.md](PRACTICE_2_3_4.md).
Результаты проверки подготовленного варианта: [VALIDATION.md](VALIDATION.md).
Исходные ноутбуки сохранены как исследовательская часть; их расширенные
зависимости не входят в окружение нового пакета. Проект учебный:
клиническая пригодность и влияние доступности признаков во времени не проверены.

### Описание проекта
Данный проект направлен на разработку модели машинного обучения для прогнозирования различных исходов у пациентов с циррозом печени. Модель будет классифицировать пациентов по нескольким категориям исходов заболевания и помогать врачам принимать более обоснованные клинические решения.

Наш проект поможет **выявлять риски летального исхода на ранней стадии** и **улучшать выживаемость пациентов** за счет своевременных медицинских вмешательств. *(мб что-то еще)*

### Цель проекта
Разработать точную модель мультиклассовой классификации исходов цирроза печени.

### Задачи проекта
1. Провести обработку данных и EDA.
2. Выполнить feature engineering *(если нужно будет)*
3. Обучить несколько моделей и сравнить результаты их обучения.
4. Представить отчет о проделанной работе.
